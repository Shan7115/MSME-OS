# MSMEOS2 — Product Roadmap (Phases 1–4)

## Phase 1 — Core MVP (Current Status: Complete & Verified)
- Local-first architecture (FastAPI + React/Vite + SQLite).
- Multi-format ingestion: PDF (PyMuPDF), DOCX, XLSX, TXT, CSV with validation.
- Deterministic fact extraction & evidence-backed finding engine.
- Interactive Executive Dashboard with Readiness Score (0–100) & breakdown.
- Findings Explorer with multi-attribute filtering and status transitions.
- Printable Executive Board Report with 30/60/90-Day priority framework.
- Zero-fabrication Validation Hub with live metric aggregation.

## Phase 2 — Pilot & Advisor Co-Creation (Months 3–4)
- Live pilot cohort with 25 manufacturing MSMEs across Tamil Nadu.
- Automated ingestion of Tally XML and Zoho Books financial export reports.
- TReDS / M1xchange automated API bridge for immediate receivable factoring.

## Phase 3 — Productization & Collaborative Workspaces (Months 5–8)
- Multi-user role-based workspaces (Promoter, CA, Credit Underwriter).
- Recurring month-over-month health monitoring across consecutive GST-3B filings.
- Multilingual regional language localization (Tamil, Hindi, Gujarati, Telugu).

## Phase 4 — Scale & Ecosystem Integrations (Months 9–12)
- Comparative peer benchmarking across 50+ NIC manufacturing codes.
- Direct NBFC / Banking syndicate underwriting pre-qualification APIs.
- Automated eligibility engine for Central & State MSME subsidy schemes (PMEGP, CGTMSE, NEEDS).
